# Tshwjxeeb Vaaj · Portfolio

Static site for GitHub Pages: home, about, and three case studies.

- Edit shared settings (email, LinkedIn, résumé, project links) at the top of `build.py`, then run `python3 build.py` to regenerate the pages.
- Scroll reveal: add `class="reveal"` to any element (optionally `d1`/`d2` for a short delay). Logic lives in `assets/js/site.js`; it respects the reduced-motion setting.
- Images: `assets/img/`. Videos: `assets/video/`.
